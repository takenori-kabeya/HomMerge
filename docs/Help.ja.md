# HomMerge ヘルプ

HomMerge は Mac 専用のファイル／フォルダ比較ツールです。2つのファイルまたはフォルダツリーを比較し、差分のマージやコピー・削除ができます。

## はじめに

1. **ファイル → 左を開く…** と **ファイル → 右を開く…** でパスを選びます（ペインへのドロップでも可）。
2. **ファイル → 比較**（⌘↩）で比較を開始します。
3. フォルダ比較では表で差分を確認し、ファイル比較では左右ペインのハイライトを確認します。

ほかにも次の方法があります。

- **ファイル → 新規ウインドウ**（⌘N）／**新規タブ**（⌘T）
- Finder で2項目を選び **サービス → HomMergeで比較**
- HomMerge のアイコン（Dock または Finder）へファイルを1〜2個ドラッグ＆ドロップ

## ファイル比較

- **Diff** メニューまたはツールバーで差分を移動します。
- 現在の差分を左右へコピーできます（続けて次の差分へ進む操作もあります）。
- **ファイル → 左を保存**（⌘S）／**右を保存**（⇧⌘S）で各側を保存します。
- マージ編集の取り消し／やり直しは **編集 → 取り消す**／**やり直す** です。

## フォルダ比較

- **Diff → 更新**（⌘R）でツリーを再読み込みします。
- 選択項目をもう一方へコピーしたり、ゴミ箱へ移動したりできます。
- **Diff → 選択したフォルダ内ファイルを比較** で、対になる（または別名の）ファイル比較を開けます。

## App Sandbox について

公式ビルドは **App Sandbox** で動作します。オープンパネル、ドラッグ＆ドロップ、Finder のサービスで得たアクセスが有効です。セッションはセキュリティスコープ付きブックマークを保存し、再起動後もパスを復元できます。

パス引数だけの起動（例: `open -a HomMerge --args /path/a /path/b`）は、サンドボックス下では失敗することがあります。UI・サービス・D&D を使ってください。
